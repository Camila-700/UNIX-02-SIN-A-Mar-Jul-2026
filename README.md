## Project Overview

This repository contains the complete development of the **Integrative Project: Build, Boot, and Attack**. The project is divided into three independent parts that demonstrate the complete workflow of a Linux system, from creating a custom distribution to booting a 64-bit kernel and deploying an offensive security laboratory.

The project consists of:

- **Part 1:** Build a custom Linux distribution using Cubic.
- **Part 2:** Develop and boot a 64-bit kernel from scratch.
- **Part 3:** Deploy and analyze the Black Hat Bash laboratory using Docker and Docker Compose.
